# mihontool

## 說明

這是基於開源漫畫軟體 [`Mihon`](https://mihon.app/) 所建制的一個 `Linux` 終端執行的 `Shell` 腳本工具集，可以用於以下條件：
1. 需要排序的圖片資料夾及漫畫檔案夾。
2. 下載下來的漫畫資料夾檔案。
3. 統一任意格式成 `.webp`。
4. 依照 `Mihon` 文本說明裡的 [`Local Source`](https://mihon.app/docs/guides/local-source/#folder-structure) 建制資料夾架構。

## 注意事項

1. 重要：請勿用來做非法用途，不鼓勵任何侵犯著作權之行爲。
2. 提供 `Shell` 腳本及使用方式，歡迎你做任何的修正修改。

## 架構及邏輯

根據 [`Mihon`](https://mihon.app/) 文本說明中的 [Local Source](https://mihon.app/docs/guides/local-source/#folder-structure) 裡的架構圖，我最終修訂了一個不會因爲人爲亂擺調整資料夾檔案或是人爲干擾因素的標記系統腳本。

### 腳本邏輯

#### markdown.sh（標記系統，核心運行腳本）
- 首先會先移除主目錄中的空資料夾，不包含目標資料夾內的空資料夾。
- 排除掉已建立的 `mf` 標記。
- 掃描並且移除其他已存在的 m 開頭標記，接著執行下面的條件判斷。
- 標記是實體的 `0byte` 檔案。

- 針對目標資料夾內，圖片數量=1：
    - 圖片名稱爲 `cover.ext`，且有一個不爲空的 `chapter_1` 資料夾，增加信標 `mi`（mark ignore）。
    - 圖片名稱爲 `cover.ext`，且有一個不爲空的 `chapter_1.cbz` 壓縮檔，增加信標 `md`（mark done）。
    - 圖片名稱不爲 `cover.ext`，且有一個不爲空的 `chapter_1.cbz` 壓縮檔或資料夾，增加信標 `m3`。
 
- 目標資料夾內，圖片數量大於1，且沒有其他子資料夾或檔案：
    - 圖片全部經過 `webp` 轉換成功，且沒有前綴 `image_XXX` 命名（XXX爲3位數字排序），增加信標 `m0`。
    - 圖片 `.ext` 未經過轉換成 `.webp`，增加信標 `m1`。
    - 圖片經過 `image_` 前綴命名，後面爲3位數數字排序，所有圖片檔名非 `webp` 者，增加信標 `m2`。
    - 圖片經過 `image_` 前綴命名，後面爲3位數數字排序，所有圖片檔名爲 `webp` 者，增加信標 `m4`。

- 上述條件都未達成：
    - 標記錯誤，增加 `mf` 標記。
    - `mf` 標記只能手動移除。

#### frename.sh（結構檢查系統）
- 只會執行帶有 `m3` 標記的資料夾，進行 `cover.ext` 的檢查及調整（非 `webp` 也可以）。
- 會檢查是否存同時在 `chapter_1` 資料夾跟 `chapter_1.cbz`。
- 會檢查是否有其他不相干的檔案，若有則標記 `mf`。

#### autoconvert.sh（第一執行）
- 只會執行帶有 `m1` 及 `m2` 標記的資料夾，進行圖片 `webp` 格式轉換。
- 單一資料夾內有檔案轉換失敗，標記 `mf`。

#### forcerename.sh（第二執行）
- 只會執行帶有 `m1` 及 `m0` 標記的資料夾，進行圖片 `image_xxx` 開頭的排序。
- 圖片可爲任意圖片檔案（`.ext`）
- 腳本執行完畢後，移除 `m1` 及 `m0` 標記，新增 `m4` 標記。
- 腳本執行轉換失敗，標記 `mf`。

#### actionmove.sh（第三執行）
- 只會執行帶有 `m4` 標記的資料夾
- 會將資料夾結構變成一張 `cover.ext` 及 `chapter_1` 資料夾。
- 成功調整結構完畢後，移除 `m4` 標記，新增 `mi` 標記。
- 結構調整失敗，標記 `mf`。

#### packcbz.sh（第四執行或不一定要執行）
- 只會執行帶有 `mi` 標記的資料夾，將 `chapter_1` 資料夾封裝成 `cbz`。
- 可選擇單獨執行或是完整流程執行。
- 封裝失敗，標記 `mf`。

#### folderstate.sh
- 資料夾當前狀態，專門統計資料夾內的所有標記。

#### mastercontrol.sh
- 控制台腳本
- 在選擇執行任何項目前都會先後執行 `markdown.sh` + `frename.sh`。

## 腳本架構

|腳本(`.sh`)|主要功能|執行項目|
|--|--|--|
|`markdown`|重新命名及排序|`image_001.ext`, `image_002.ext`, `image_n.ext` 排序|
|`folderstate`|資料夾狀態統計|掃描標記及資料夾|
|`autoconvert`|轉換檔案格式|將任意圖片檔案轉換爲 `.webp` 格式|
|`forcerename`|重新命名及排序|`image_001.ext`, `image_002.ext`, `image_n.ext` 排序|
|`actionmove`|移動檔案及調整架構|將 `image_n.webp` 移入 `chapter_1` 及定義 `image_001.webp` 作爲 `cover.webp` 使用|
|`packcbz`|封裝 `chapter_1.cbz`|封裝完畢之後移除 `chapter_1` 資料夾|
|`frename`|檢查封面是否存在|`anyname.ext`變更爲`cover.ext`|
|`mastercontrol`|控制台|統合執行流程|

## 使用方式及環境

### A、使用環境

我個人是使用 `Linux Mint` 作爲開發環境去建制這個腳本集，其他 `Linux` 版本的使用方式因系統終端指令差異我就不提及了。

1. 將 `mihontool` 資料夾內部的 `5` 個 `shell` 腳本直接複製到你的漫畫資料夾主目錄。

2. 開啓終端機（`Terminal`），指向你的漫畫資料夾主目錄：

```bash
cd ~/[your_comic_folder]
```
3. 使用 `chmod` 指令來升級腳本權限，供 `shell` 腳本正常使用：
```bash
chmod +x mastercontrol.sh
```
4. 輸入下面的指令啓動 `shell` 腳本：
```bash
 ./mastercontrol.sh
```
5. 每次執行項目完畢之後，`Enter鍵`會清除已執行完畢的結果（`clear`）保持終端機乾淨。
